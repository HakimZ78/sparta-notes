# Take-Home Tasks

---

## Required: Documentation

1. **Centralise and complete your documentation** of what you covered this week
   - Host on GitHub
   - Use subfolders preferably
   - Ensure the documentation is usable by others and of a standard that would impress industry professionals
2. **Upload your repo** in the submission page provided
   - We will aim to review your documentation and provide feedback
   - Skills Sprint completion badge will be issued once reviewed (this may take time)

---

## Optional 1: CI/CD Pipelines

- What are they? How do they work? What software can you use?
- What is CI? What is CD?
- Implement a **CI Pipeline with GitHub Actions** (feel free to use the Sparta app as dummy code)
- Try to set up a **Jenkins server** — can you implement CI on there too? (more complex)

---

## Optional 2: Docker & Containerisation

- How does it work? What are containers?
- Can you run a piece of software as a container?
- Can you **containerise the Sparta app**?
- Can you host the image on **Docker Hub**?
- Can you use **Docker Compose** to spin up both the app and the database in separate containers, and connect them?

## Optional 3: Deploy a Web App (Full SDLC)

- Develop a website or web app and deploy it on AWS/Azure/GCP using the techniques learned this week
- If you have something already, deploy that
- Follow the full SDLC stages: **Plan → Code → Build → Test → Deploy → Monitor**
- Document the process to add to your portfolio
- Try implementing CI and/or CI/CD (GitHub Actions, Jenkins etc.)
- Containerise your app?
- Feel free to submit your documentation in the page provided
